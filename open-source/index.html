HAN

HANporten.se

a practical guide to the meter’s local interface

An open guide to Swedish electricity meters’ HAN/P1 interfaces, with protocol information and examples for reading local data.

Swedish electricity meters expose local customer interfaces with differing connectors and protocol conventions; builders need clear, usable guidance to connect their own equipment.

A free public-good electricity-price API and analysis site with static JSON endpoints, day-ahead graphs, historical data and push notifications.
