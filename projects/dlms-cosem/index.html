dlms-cosem — practical protocol engineering

Henrik is actively maintaining a Python DLMS/COSEM library for device integrations over serial and IP transports.

CONTEXT

The problem

Interoperating with real meters requires more than a standards checklist: sessions, transport, security and data formats all have to work together.

RESPONSIBILITY

What Henrik owned

Henrik created the library and continues to maintain and extend it for u9n’s own and client integration use cases.

DELIVERY

Work delivered

  • Implemented protocol encoding, decoding and association handling
  • Supported authenticated and encrypted exchanges and common operations
  • Provided serial HDLC and TCP integration paths
  • Continues to add features driven by real meter-integration needs
OUTCOME

Where it stands

The open-source library is in active development for u9n’s own and client meter integrations.
