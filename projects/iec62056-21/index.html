iec62056-21 — local energy-meter readout

Python library for local meter readout over optical, serial and network connections, including HAN/P1 data handling for Swedish electricity meters.

CONTEXT

The problem

Field devices and local meter interfaces often use IEC 62056-21, IEC 61107, LIS-200 or HAN/P1 style data rather than a uniform modern API.

RESPONSIBILITY

What Henrik owned

Henrik created the library and provides ongoing support, with limited day-to-day activity because the project is mature.

DELIVERY

Work delivered

  • Implemented IEC 62056-21 / IEC 61107 communication
  • Supported serial and TCP transport and derivative handling
  • Handled data from HAN ports on Swedish electricity meters
  • Maintains the library as practical open-source tooling
OUTCOME

Where it stands

Public library supporting repeatable integration with local meter interfaces and HAN/P1 data handling.
