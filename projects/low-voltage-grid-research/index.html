IoT in low-voltage electricity grids

Designed and built a simulation platform to evaluate distributed intelligence and Connode 6LoWPAN mesh communication in low-voltage grids.

CONTEXT

The problem

An industry pilot in Malmö explored next-generation metering and low-voltage-grid use cases using the Connode mesh system.

RESPONSIBILITY

What Henrik owned

Henrik interviewed utility staff, defined use cases, built simulation boxes and developed Python networking software for communication over 6LoWPAN.

DELIVERY

Work delivered

  • Translated utility needs into low-voltage-grid use cases
  • Built decentralized Arduino-based I/O in simulation boxes
  • Used a small embedded Linux environment
  • Developed Python networking software to communicate over the 6LoWPAN mesh
  • Evaluated the Connode mesh system for distributed grid intelligence
OUTCOME

Where it stands

Published as university/industry research on low-voltage grid IoT and distributed intelligence.
