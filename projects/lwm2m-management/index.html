LwM2M management bridge

Built a Leshan-based LwM2M bridge so a Django management system could control devices without implementing LwM2M, CoAP and DTLS in Python.

ONE Nordic
CONTEXT

The problem

ONE Nordic needed device management for constrained NB-IoT devices, but the management application was built in Django while the LwM2M protocol stack was better handled by Leshan.

RESPONSIBILITY

What Henrik owned

Henrik designed and implemented the Leshan bridge, Redis queue communication and LwM2M bootstrap server.

DELIVERY

Work delivered

  • Built a Leshan-based bridge between Django and LwM2M devices
  • Used Redis queues for communication between the management application and protocol bridge
  • Kept LwM2M, CoAP and DTLS handling out of the Python application
  • Implemented a LwM2M bootstrap server
  • Integrated the bridge with the Django management system
APPROACH

Technical approach

The Django application handled the management interface and business logic, Redis queues carried commands and responses, and the Leshan-based bridge handled LwM2M, CoAP and DTLS communication with devices.

OUTCOME

Where it stands

The bridge worked. Device management later moved to another solution when firmware update handling became the main project need, while the bootstrap server remained in production.
