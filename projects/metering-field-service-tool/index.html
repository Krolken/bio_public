Utilitarian FSM — field-service software for meter exchange

Utilitarian FSM is an ongoing Progressive Web App for meter exchange field work, including barcode scanning, image documentation, validation and business-system exports.

Nordion Energi
CONTEXT

The problem

Utilitarian FSM supports meter exchange field teams with a repeatable way to document work, validate captured data and pass the right information into existing business workflows.

RESPONSIBILITY

What Henrik owned

Henrik delivers and operates Utilitarian FSM, including the Progressive Web App, field workflows and file-generation integrations.

DELIVERY

Work delivered

  • Delivered the solution as a Progressive Web App for multiplatform support without app-store distribution
  • Built field workflows for meter exchanges
  • Added barcode scanning for meter and installation data
  • Added image documentation for field work
  • Implemented validation across multiple meter types and media
  • Generated files for automated changes in the customer’s business system
  • Operated and monitored the application in a managed cloud environment
OUTCOME

Where it stands

The application is in ongoing delivery and supported a gas meter exchange project of approximately 8,000 meters.
