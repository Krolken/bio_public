Next-generation smart meter procurement

Supported E.ON’s next-generation smart meter procurement as a smart meter communication and integration expert.

E.ON
CONTEXT

The problem

E.ON was procuring next-generation smart meters while evaluating NB-IoT with different mobile network operators.

RESPONSIBILITY

What Henrik owned

Henrik handled DLMS/COSEM-specific requirements and worked as a smart meter communication and integration expert. In parallel, he built test hardware for NB-IoT evaluation and assessed coverage, data throughput and DLMS/COSEM behaviour over NB-IoT.

DELIVERY

Work delivered

  • Defined and reviewed DLMS/COSEM-specific procurement requirements
  • Advised on smart meter communication and integration
  • Ran NB-IoT evaluation tests with different mobile network operators
  • Built dedicated test hardware
  • Focused testing on coverage, data throughput and DLMS/COSEM behaviour over NB-IoT
APPROACH

Technical approach

The work combined procurement requirements with practical communication testing: translate DLMS/COSEM needs into tender material, then verify how the protocol behaved over NB-IoT under different network conditions.

OUTCOME

Where it stands

Contributed during the procurement and NB-IoT evaluation phase before moving to a new assignment.
