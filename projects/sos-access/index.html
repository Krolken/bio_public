sos-access — alarm integration client

A reusable Python client for sending structured alarm messages through SOS Access v4.

CONTEXT

The problem

The EVC alarm integration needed a maintainable way to send alarms to alarm-management systems using SOS Access v4.

RESPONSIBILITY

What Henrik owned

Henrik implemented and open-sourced the client library as part of the alarm integration work.

DELIVERY

Work delivered

  • Implemented the SOS Access v4 API client
  • Tested the library against SOS Alarm, Nokas/Avarn and Örnsköldsviks Brand och Säkerhet KAC
  • Published the client for reuse
OUTCOME

Where it stands

The original EVC alarm solution that used the library is no longer in use. The library is not under ongoing feature development because it is close to feature complete for its intended protocol scope.
