Multi-utility metering and integration platform

A cloud-native AMR platform for collecting, processing and integrating meter data across protocols, devices and utility operations.

CONTEXT

The problem

Utilities need meter data collection that can handle different energy types, meters, communication protocols and downstream business systems without making every integration a one-off system.

RESPONSIBILITY

What Henrik owned

Henrik founded and developed the product, working across architecture, protocol integration, software, deployment and operations.

DELIVERY

Work delivered

  • Built the main API for meter inventory, installations, measurements, organizations and readout scheduling
  • Designed asynchronous processing around RabbitMQ for polling, parsing and onward integration
  • Implemented push-data receiving and processing services, including DLMS message handling
  • Used PostgreSQL as the operational database
  • Packaged services as Docker containers for flexible deployment
  • Exposed REST APIs and documented message streams for integrations and downstream systems
APPROACH

Technical approach

Utilitarian separates the platform API, protocol-specific receiving services, processors, queue consumers, PostgreSQL storage and RabbitMQ broker so each part can be deployed and scaled independently. The model supports multi-tenant utility operations while allowing only the services needed for a given deployment to run.

OUTCOME

Where it stands

Around 4,000 gas meters are managed through the platform today in production at clients.
